# Ipangax

**Ipangax** é uma linguagem de programação criada por **Elisandro Ipanga**, inspirada em Python, C++ e Rust.

O seu objetivo é oferecer uma sintaxe simples, uma estrutura eficiente e ferramentas que facilitem o desenvolvimento de software, com especial atenção à **programação competitiva**.

## Sobre o projeto

O ecossistema Ipangax é composto por três pilares:

- **Linguagem de programação:** uma linguagem própria, com compilador e funcionalidades em desenvolvimento.
- **Plataforma de desafios:** um ambiente de aprendizagem onde os programadores podem praticar e melhorar as suas competências.
- **Competição Ipangax:** uma iniciativa para incentivar a programação competitiva, promover talentos e desafiar programadores.

## Compilador

O compilador da Ipangax é desenvolvido em C++17 e inclui:

- Análise léxica (Lexer).
- Análise sintática (Parser).
- Árvore sintática abstrata (AST).
- Verificação de tipos.
- Interpretador.
- Interface de linha de comandos (CLI).

## Funcionalidades

O projeto já inclui funcionalidades como:

- Estruturas de dados.
- Maps e Sets.
- Heaps e Deques.
- Operações matemáticas.
- Operações com bits.
- Testes automatizados.

## Objetivo

A Ipangax pretende tornar a programação mais acessível, incentivar a aprendizagem prática e facilitar a participação em competições de programação.

Language

Statements end at a new line. Types are inferred, or written explicitly. Functions declare their types. Arrays, loops and input are built in.

name = "Elisandro"
int age = 20
const NOTA_MINIMA = 10.0

fn add(int a, int b) -> int {
    return a + b
}

if add(10, 20) > 20 {
    print(name)
}

Project status

Ipangax is at an early stage (v0.5, draft). This is what exists today.

Lexer, parser, type checker, interpreter (C++17)Implemented
CLI: ipx run, check, version, helpImplemented
Variables, const, if/else, while, functionsImplemented
Arrays, for, do-while, match, ?:, break/continue, +=, input(), strings, math built-insImplemented
Structs, maps, sets, heaps, deques, bit operators, math functionsImplemented
Enums, optional, result, tuples, modules, struct methodsNot implemented yet
ipx build, ipx fmt, ipx replNot implemented yet
Playground (runs the real interpreter on the server, Netlify Function)Implemented
Playground in the browser via WebAssemblyNot implemented yet
VS Code extension, language serverNot implemented yet
Native compilation (LLVM)Not implemented yet

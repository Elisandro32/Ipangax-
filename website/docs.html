Introduction

Ipangax is a programming language by Elisandro Ipanga. The goal: Python-like simplicity, C++-like performance and Rust-inspired safety, without copying any of them. Source files use the .ipa extension and the command line tool is ipx.

Version 0.1 is a draft. It runs through a tree-walking interpreter. Native compilation, performance and memory-safety features beyond bounds and overflow checks are goals, not features. Pages below mark what does not exist yet.

Installation

There are no downloads or releases yet. Build from source. You need a C++17 compiler (GCC or Clang) and make.

make
./ipx run examples/mvp.ipa

On Windows, use WSL. Source hosting: not published yet. To try code without installing anything, use the Playground.

Hello World

print("Hello, Ipangax")

Top-level statements run in order. An optional fn main() runs after them.

fn main() {
    print("Hello, Ipangax")
}

Variables

name = "Ipangax"        // declares, type inferred: string
int age = 20            // declares with explicit type
age = age + 1           // assigns
age += 1                // also -=  *=  /=  %=
const PI = 3.14159      // immutable

x = value declares x when no visible variable has that name, otherwise it assigns. The type is fixed at the first assignment. A typed declaration requires an initial value.

Scope: every { } block is a scope. Declaring a name twice in the same scope is an error; a typed declaration in an inner scope may shadow an outer variable. Functions see their own parameters and locals plus top-level consts, not other global variables.

Types

int64-bit signed integer
float64-bit floating point
stringtext
booltrue or false
charone byte, written 'a'

There are no implicit conversions. Use int(x), float(x) and string(x). Arrays are written int[], string[], int[][] and so on. Maps, sets, heaps, deques and structs are covered below. Enums, optional and result: Not implemented yet.

Operators

From lowest to highest precedence: ||, &&, == !=, < <= > >=, + -, * / %, unary - !.

+ - * / need two ints or two floats; + also joins strings. % needs ints. Integer division truncates toward zero. Integer overflow and division by zero are runtime errors. Compound assignment (+=, -=, *=, /=, %=, &=, |=, ^=, <<=, >>=) works on variables, array elements and struct fields.

Bit operators & | ^ ~ << >> work on ints and bind tighter than comparisons, so x & 1 == 0 means (x & 1) == 0. A shift count must be 0 to 63, and a left shift that loses bits is an overflow error.

Conditions

if score >= 90 {
    print("A")
} else if score >= 70 {
    print("B")
} else {
    print("C")
}

Conditions must be bool. } else { stays on one line.

match day {
    1 { print("Monday") }
    2, 3 { print("Tuesday or Wednesday") }
    else { print("other") }
}

label = n % 2 == 0 ? "even" : "odd"

match works on int, string, char and bool, runs the first matching arm and has no fall-through. else is optional and last. The ternary c ? a : b needs a bool condition and branches of the same type, and only evaluates the chosen branch.

Loops

i = 0
while i < 3 {
    print(i)
    i = i + 1
}
for item in items {        // array elements, or the chars of a string
    print(item)
}
for i in range(5) { }      // 0 to 4
for i in range(2, 8) { }   // 2 to 7
for i in range(9, 0, -3) { }
break
continue

range only works inside for and does not build an array. The loop variable exists only in the loop body.

do {
    tries += 1
} while tries < 3

do { } while runs the body at least once. There is no C-style for (;;): use range with a step, or while.

Functions

fn add(int a, int b) -> int {
    return a + b
}

fn greet(string name) {
    print("Hello " + name)
}

Top level only, any order, recursion allowed, no overloading. A function with a return type must return on every path. main takes no parameters and returns nothing.

Arrays

int[] a = [5, 3, 8]
b = [1, 2, 3]            // inferred int[]
grid = make(3, make(3, 0))   // 3 x 3 table of zeros
a[0] = 10
push(a, 7)
print(len(a))
sort(a)

All elements share one type. An empty array needs a declared type: int[] a = []. Indexing is bounds-checked: a bad index is a runtime error with line and column, never undefined behavior. Arrays are shared references, like Python lists: b = a makes both names point to the same array. Use copy(a) for an independent copy. Arrays cannot be const yet.

Collections

map[string, int] count = {}      // ordered by key
count["a"] = 1
x = get(count, "z", 0)           // default for a missing key
if has(count, "a") { }
for k in count { print(k) }      // keys in order

set[int] seen = {}
add(seen, 3)
s = {1, 2, 3}

heap[int] h = {}                 // min-heap; maxheap[int] for a max-heap
push(h, 5)
smallest = pop(h)

deque[int] q = {}                // queue, stack and deque
push(q, 1)
push_front(q, 0)
a = pop_front(q)

{} is the empty literal for any of these and needs a declared type. Keys and set elements are int, string, char or bool. Reading a missing key is a runtime error. These types are shared references like arrays; copy(c) makes a deep copy. There are no tuples yet: pack two numbers into one int, for example (dist << 10) | node.

Structs

struct User {
    string name
    int age
}

u = User(name = "Ana", age = 20)
v = User("Bo", 30)
u.age += 1
print(u)                         // User(name = "Ana", age = 21)
User[] users = []
push(users, u)

Declared at the top level, one field per line, in any order. Every field must be given when constructing. Structs are shared references: b = a points to the same struct, and copy(a) makes an independent one. A struct cannot contain itself directly (use an array of its own type) and cannot be compared with ==. Methods: Not implemented yet.

Error Handling

Compile-time errors show file, line, column, the source line and a caret, and all type errors found are listed. Runtime errors (division by zero, overflow, invalid conversion, index out of bounds, reading past the end of input, call depth above 1000) use the same format and keep output printed before the error. A result type for user-level error handling: Not implemented yet.

CLI

ipx run main.ipa      check and run (input() reads standard input)
ipx check main.ipa    check only
ipx version
ipx help

ipx run main.ipa --max-steps N   stop after N statements
ipx run main.ipa --max-array N   limit array length

Example: echo "3 4" | ipx run examples/abc_product.ipa

ipx build, ipx fmt and ipx repl: Not implemented yet. Exit codes: 0 success, 1 program or compile error, 2 usage error.
